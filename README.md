# Space Invaders

A classic Space Invaders clone in a single HTML file — no dependencies, no build step. Rendered on `<canvas>` with Web Audio sound effects.

**[▶ Play it here](https://github.freaxnx01.ch/game-space-invaders/)**

## Controls

| Key | Action |
|---|---|
| ← → or A / D | Move |
| Space | Fire |

## Features

- 5×11 invader grid (squids 30 pts, crabs 20 pts, octopuses 10 pts) with 2-frame marching animation
- March speeds up as invaders are destroyed; waves get faster
- Destructible shields, chewed by both bullets and bombs
- Mystery UFO worth 50–300 points
- Retro square-wave sound effects (4-note descending march)
- Persistent high score via `localStorage`

## Run locally

Open `index.html` in any browser. That's it.
